# Denial of Service (DoS)

## Overview

A Denial of Service (DoS) attack attempts to make a system unavailable by exhausting its computing or network resources. Unlike DDoS attacks, a DoS attack usually originates from a single source.

## Characteristics

- Single attacking source
- Resource exhaustion
- Service slowdown
- High request frequency

## Detection Indicators

- Excessive requests from one IP
- Increased CPU utilization
- High memory usage
- Network congestion

## Impact

- Temporary service outage
- Reduced availability
- Business disruption
- Financial losses

## Mitigation

- Firewall filtering
- Request rate limiting
- Blacklisting attackers
- Traffic monitoring

## Prevention

- Continuous monitoring
- IDS deployment
- Network hardening
- Software updates
