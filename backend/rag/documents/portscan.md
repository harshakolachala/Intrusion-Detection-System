# Port Scanning Attack

## Overview

Port scanning is a reconnaissance technique used to identify open ports, running services, and operating systems on a target machine. Attackers perform port scans before exploiting vulnerabilities.

## Characteristics

- Sequential port probing
- TCP or UDP scans
- Service discovery
- Network reconnaissance

## Detection Indicators

- Connections to many ports
- Short-duration connection attempts
- SYN scan activity
- Multiple failed connection requests

## Impact

- Exposure of vulnerable services
- Increased attack surface
- Information disclosure

## Mitigation

- Firewall rules
- Close unused ports
- IDS monitoring
- Network segmentation

## Prevention

- Regular vulnerability scanning
- Least privilege configuration
- Disable unnecessary services
- Continuous monitoring
